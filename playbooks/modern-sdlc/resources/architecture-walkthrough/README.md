## Architecture Walkthrough Workshop

**Example-authored facilitated activity, not a runnable software demonstration.** No video or compatible binary project is included.

### Preparation

Bring a system boundary sketch, one change scenario, and the original Actor Framework presentation. Use public or distribution-approved material only in this reference instance.

### Facilitation Script

1. Describe the current measurement and its hardware boundary.
2. Ask where the measurement's state lives and who can change it.
3. Trace a command, result, error, and shutdown through the system.
4. Introduce a proposed new measurement or instrument.
5. Identify which responsibilities and interfaces change.
6. Choose a verification activity that would reveal an unintended consequence.
7. Record the decision, remaining questions, and owner of the next experiment.

### Evidence to Retain

Keep the before/after responsibility map, proposed acceptance condition, reviewed source revision if applicable, and unresolved dependencies. Do not mark the activity complete simply because the presentation was delivered.

### Dependencies and Limitations

This workshop requires knowledgeable participants, not a verified LabVIEW runtime. It has no embedded video, source browser, generated technical report, or executable sample. Those remain explicit content gaps.
